# oh-my-mermaid (omm) Skill

This skill manages the living architecture diagrams for LifeOS inside `.omm/`.

## Usage Commands

- **Validate Diagrams**: `npx omm validate`
- **View Interactive Tree**: `npx omm tree overall-architecture`
- **Launch Interactive Web Viewer**: `npx omm view`
- **Check Status**: `npx omm status`
